# Carbohydrates — impress.js presentation

A medical-biochemistry presentation built on the official impress.js presentation framework.

## Run
Open `index.html` in a modern browser. For deployment to Vercel, upload this folder as a static site.

## Design direction
Dark clinical interface, mint/cyan biochemistry accents, 3D camera movement, molecular diagrams, pathway layouts, and CSS-triggered micro-animations.
