# Carbohydrate Chemistry — impress.js V6

- Real impress.js 2.0.0 3D camera navigation.
- Every step starts visually empty.
- Click/tap or Space/Right Arrow reveals one content block at a time; after the last block, the next click moves to the next 3D step.
- Animated entrances for cards, diagrams, circles and SVG lines.
- Varied light/dark/warm/violet/mint/navy themes.
- The Doc_Sh logo appears on every step.
- Fullscreen start gate and annotation toolbar retained.

The presentation loads impress.js from the official jsDelivr CDN, so the browser needs internet access.
